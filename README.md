# ComputeRaft

ComputeRaft delivers a horizontally scalable and fault-tolerant engine for distributed applications, enabled by automated load-balancing and adaptive scaling.

ComputeRaft is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/fuad403273/ComputeRaft.git`
2. `cd ComputeRaft`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
